# 1. 5-буквенные коды из букв

**Условие:**
Тимофей составляет 5-буквенные коды из букв Т, И, М, О, Ф, Е, Й. Буква Й может использоваться в коде не более одного раза, при этом она не может стоять на первом месте, на последнем месте и рядом с буквой И. Все остальные буквы могут встречаться произвольное количество раз или не встречаться совсем. Сколько различных кодов может составить Тимофей?

**Описание проделанной работы:**
Программа перебирает все возможные комбинации из 7 букв длиной 5 с помощью itertools.product. Для каждой комбинации проверяются три условия: буква «Й» встречается не больше одного раза; если она есть, то не стоит ни в начале, ни в конце слова; и не соседствует с буквой «И» (ни слева, ни справа). Комбинации, прошедшие проверку, подсчитываются, и в результате выводится общее количество подходящих кодов.

# 2. Количество единиц в 2-ой записи

**Условие:**
Сколько единиц содержится в двоичной записи значения выражения 4^2020 + 2^2017 - 15?

**Описание проделанной работы:**
Сначала вычисляется значение выражения 4^2020 + 2^2017 - 15. Затем с помощью цикла, в котором число делится на 2, проверяется каждый двоичный разряд: если остаток равен 1, счётчик единиц увеличивается. В конце выводится общее количество единиц в двоичной записи.

# 3. Числа, имеющие ровно два различных натуральных делителя

**Условие:**
Найдите среди целых чисел, принадлежащих числовому отрезку [174457;174505][174457;174505], числа, имеющие ровно два различных натуральных делителя, не считая единицы и самого числа. Для каждого найденного числа запишите эти два делителя в два соседних столбца на экране с новой строки в порядке возрастания произведения этих двух делителей. Делители в строке также должны следовать в порядке возрастания. Например, в диапазоне [5; 9][5; 9] ровно два различных натуральных делителя имеют числа 6 и 8, поэтому для этого диапазона вывод на экран должен содержать следующие значения:

**Описание проделанной работы:**
Программа перебирает все числа из заданного диапазона. Для каждого числа ищутся делители, начиная с 2 и до квадратного корня из числа. Найденные делители (вместе с парными) сохраняются в список. Если в списке оказалось ровно два делителя (не включая 1 и само число), пара запоминается. Найденные пары сортируются по возрастанию самого числа (так как произведение двух делителей равно числу). Затем на экран построчно выводятся сначала меньший делитель, потом больший.
